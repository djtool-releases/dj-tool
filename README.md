# DJ Tool — downloads

Grab a track from a file or a YouTube link, tag it with BPM and key, and split it into stems
(vocals, drums, bass, other) that line up sample-for-sample for group-warping in Ableton.

**This repository only hosts the builds.** Head to the **[Releases](../../releases)** page and pick
the download for your Mac — Apple menu → *About This Mac* → *Chip*:

| Your Mac | Download | Then |
|---|---|---|
| **Apple Silicon** (M1 / M2 / M3 / M4…) | `DJ-Tool-<version>-apple-silicon.dmg` (~400 MB) | Drag to Applications. That's it — the audio engines are built in. |
| **Intel** | `DJ-Tool-<version>-universal.dmg` (~180 MB) | Drag to Applications, then run the one-time installer from the app's setup screen. |
| **Windows 10/11** (64-bit) | `DJ-Tool-<version>-windows-x64.exe` (~360 MB) | Run it. Not code-signed yet, so click **More info → Run anyway** on the SmartScreen prompt. |

The Mac builds are signed and notarized by Apple, so they open normally with no warnings. The Windows build is new and unsigned — see the release notes.
